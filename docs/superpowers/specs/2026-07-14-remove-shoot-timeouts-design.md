# 删除飞镖发射超时检测设计

## 目标

删除飞镖发射状态机中所有以时间超限为条件进入故障状态的检测，使3508和装填机构持续等待实际到位或完成信号。

## 修改范围

- 删除单程运动超过3000 ms后进入 `shoot_motion_timeout` 的两处判断。
- 删除装填超过8000 ms后进入 `shoot_reload_timeout` 的判断。
- 删除整轮齐射超过30000 ms后进入 `shoot_salvo_timeout` 的判断。
- 删除仅为齐射超时服务的计时状态和维护代码。

## 保留行为

- 保留原点速度稳定500 ms后记录初始角度。
- 保留左右3508到位并稳定100 ms的判断。
- 保留左右同步误差持续100 ms后进入同步故障的检测。
- 保留扳机锁定和开火各500 ms的动作节拍。
- 保留三个装填序列中每一步的舵机等待时间。
- 保留电机离线、同步错误、装填执行错误和内部状态错误。

## 状态机结果

3508未到位时，状态机持续停留在 `load_cock` 或 `load_return`。装填序列未完成时，状态机持续停留在 `load_reload`。这些状态不再因为等待时间过长自动进入 `shoot_error`。

## 验证

- 增加静态测试，确认状态机源码不再包含三类超时故障触发。
- 增加状态机测试，模拟等待时间远超原阈值后仍停留在当前动作状态。
- 运行现有遥控器、方向、扳机和装填映射测试。
- 重新构建完整固件。
